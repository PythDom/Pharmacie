📖 Mode d'emploi

Ouvrir l'app

Pharmacie tient l'inventaire de votre pharmacie familiale : on scanne chaque boîte, l'app retrouve le médicament dans la base officielle belge et lit la date de péremption. Elle vous prévient quand une boîte est bientôt périmée et tient la liste de ce qu'il faut racheter.

1Installer l'app

Android : l'application (recommandé)

  1. Sur le téléphone, ouvrez la page de la dernière version et touchez le fichier Pharmacie-….apk.
  2. Ouvrez le fichier téléchargé. Android demande d'autoriser votre navigateur à installer des applications : acceptez.
  3. Si Play Protect affiche « Application inconnue », choisissez Installer quand même.
Pourquoi l'application plutôt que le site ? Elle garde ses données à part du navigateur : vous pouvez effacer l'historique et les données de Chrome sans perdre votre inventaire ni votre jeton de synchronisation.

Android ou PC : depuis le navigateur

Ouvrez pythdom.github.io/Pharmacie dans Chrome ou Edge, puis menu ⋮ → Installer l'application. L'app fonctionne aussi hors ligne.

iPhone / iPad

Ouvrez le lien dans Safari, touchez Partager → Sur l'écran d'accueil.

Attention si vous utilisez le navigateur L'inventaire et le jeton sont enregistrés dans le navigateur. Effacer ses données (cookies, données de sites) les supprime de l'appareil. L'inventaire revient si la synchronisation est configurée, mais il faut recoller le jeton. Sur Android, préférez l'application.

2Synchroniser (facultatif)

Sans rien configurer, l'app fonctionne uniquement sur l'appareil. La synchronisation enregistre l'inventaire dans un dépôt GitHub privé : il est alors partagé entre vos appareils (téléphone, PC…) et sauvegardé.

Cas 1 : quelqu'un vous a préparé l'accès

Vous avez reçu un nom de dépôt (ex. PythDom/Pharmacie-data) et un jeton (une longue clé qui commence par github_pat_) :

  1. Dans l'app, ouvrez Réglages.
  2. Collez le dépôt et le jeton, puis touchez Enregistrer / activer.
  3. En haut à droite, l'indicateur passe à synchronisé.

Faites la même chose sur chacun de vos appareils.

Cas 2 : créer votre propre espace

  1. Créez un compte gratuit sur github.com.
  2. Créez un dépôt : github.com/new → nom, par ex. Pharmacie-data → cochez Private et Add a README file → Create repository.
  3. Créez un jeton : github.com/settings/personal-access-tokens/new
    • Token name : par ex. « Pharmacie téléphone ».
    • Expiration : la plus longue proposée (ou « No expiration »). Il faudra en créer un nouveau à l'échéance.
    • Repository access : Only select repositories → votre dépôt Pharmacie-data uniquement.
    • Permissions → Repository permissions → Contents : Read and write. Rien d'autre.
    • Generate token, puis copiez-le tout de suite : GitHub ne l'affiche qu'une fois.
  4. Dans l'app : Réglages → dépôt votre-nom/Pharmacie-data + le jeton → Enregistrer / activer.
Astuce Gardez le jeton dans votre gestionnaire de mots de passe : vous le recollerez facilement sur un nouvel appareil.

Si vous aviez déjà ajouté des boîtes avant de configurer la synchronisation, l'app propose de les importer dans le dépôt.

3Ajouter une boîte

  1. Touchez Scanner en bas, mode ➕ Ajouter une boîte. Autorisez l'accès à la caméra la première fois.
  2. Visez le petit code carré (DataMatrix) de la boîte. S'il n'y en a pas, visez le code-barres classique.
  3. Vérifiez la fiche qui s'ouvre, complétez si besoin (emplacement, note, nombre de boîtes), puis Enregistrer.
Ce qui est sur la boîteCe que l'app remplit
Code carré DataMatrix
médicaments sur prescription		Nom, conditionnement, date de péremption, lot. Rien à taper.
Code-barres classique
beaucoup de produits sans ordonnance		Le nom si le produit est connu. La date est à saisir à la main (elle est imprimée sur la boîte).
Produit inconnuTapez le nom : l'app propose les produits de la base pendant que vous écrivez. Elle retient ce code pour les fois suivantes.

Autres façons d'ajouter, sur l'écran Scanner :

  • 📷 Depuis une photo : une photo du code, si la caméra en direct ne fonctionne pas.
  • Taper le code CNK (7 chiffres, imprimé sur les boîtes belges) ou le code-barres, puis OK.
  • Saisie manuelle : chercher le médicament par son nom.
Deux boîtes identiques ? Si la date et l'emplacement sont les mêmes, elles sont regroupées (×2). Une même boîte (code carré) scannée deux fois est détectée et refusée.

4Lire l'inventaire

Chaque carte affiche le nom, à quoi sert le médicament (en vert, avec la substance active), la date de péremption, l'emplacement et vos notes.

BadgeSignification
juin 2027En ordre : mois de péremption.
24 jPérime bientôt : jours restants (moins de 60 jours, réglable dans Réglages).
PériméDate dépassée : à rapporter en pharmacie.
Niveau basPresque vide (voir section 5).

Les filtres en haut (Niveau bas, Bientôt périmés, Périmés) et la barre de recherche aident à s'y retrouver. Boutons de chaque carte :

  • 📄 Notice : la notice officielle pour le patient (PDF).
  • Modifier : corriger la date, l'emplacement, le nombre, ou supprimer.
Important « À quoi ça sert » indique la classe du médicament, à titre indicatif. Elle ne remplace ni la notice, ni l'avis de votre médecin ou pharmacien.

5Boîte vide, niveau bas

  • Boîte terminée : touchez Vide sur la carte, ou scannez la boîte en mode 🗑️ Boîte vide. S'il en reste plusieurs, une seule est retirée. À la dernière, l'app propose Retirer + refill pour la racheter.
  • Presque vide : touchez Niveau bas. La boîte reste dans l'inventaire et le médicament s'ajoute au refill. Niveau OK annule.

6La liste de refill

L'onglet Refill contient ce qu'il faut racheter. Le nombre s'affiche sur l'onglet.

  • Ajouter à la main : tapez un nom en haut (la base fait des propositions), puis Ajouter.
  • À prévoir : bientôt périmés : l'app propose les médicaments qui vont périmer, sauf si vous en avez une autre boîte encore bonne. Ajouter au refill ou Ignorer.
  • Partager / copier la liste : l'envoyer par message, ou la montrer en pharmacie. Les codes CNK sont inclus.
  • Acheté ✓ retire un produit de la liste. Plus simple encore : scannez la nouvelle boîte, elle sort du refill toute seule.

7Plusieurs personnes

Un dépôt = un inventaire.

  • Une pharmacie commune (la famille) : tout le monde utilise le même dépôt. Les ajouts de chacun sont fusionnés automatiquement.
  • Des pharmacies séparées : chacun son dépôt et son jeton.
  • Plusieurs inventaires sur un même appareil : dans Réglages, choisissez un autre dépôt dans la liste, puis Enregistrer / activer. Chaque profil garde son propre inventaire, sans mélange. Le profil actif s'affiche en haut de l'écran.

8Données et vie privée

  • Votre inventaire est enregistré sur l'appareil et, si vous l'avez configuré, dans votre dépôt GitHub privé. Il n'est envoyé nulle part ailleurs.
  • Le jeton reste sur l'appareil. Il ne donne accès qu'au dépôt choisi. Vous pouvez le révoquer à tout moment sur github.com/settings/personal-access-tokens.
  • Toute personne qui possède le jeton d'un dépôt peut lire et modifier cet inventaire. Ne le partagez qu'avec les personnes concernées.
  • Les médicaments viennent de la base publique SAM (AFMPS / eHealth), mise à jour chaque semaine. Pour les produits absents, l'app interroge Open Food Facts et ses projets voisins avec le seul code-barres.
  • Oublier ce profil efface le jeton et l'inventaire de l'appareil. Les données synchronisées restent dans le dépôt.
  • Exporter (JSON) crée une copie de sauvegarde. Importer… la fusionne avec l'inventaire actuel.

9Problèmes fréquents

La caméra ne s'ouvre pas

Autorisez la caméra : dans l'app Android, via Paramètres Android → Applis → Pharmacie → Autorisations. Dans le navigateur, via l'icône à gauche de l'adresse. Sinon, utilisez 📷 Depuis une photo ou tapez le code.

Le code n'est pas lu

Éclairez bien la boîte, tenez-la à 10–15 cm et visez le code carré plutôt que le code-barres. Une boîte cabossée ou brillante se lit mieux en photo.

Le produit est « inconnu »

C'est fréquent pour les produits sans ordonnance et la parapharmacie : la base officielle ne connaît pas leur code-barres. Tapez le nom et choisissez dans les propositions. L'app retiendra ce code pour la prochaine fois.

Pas de date de péremption après le scan

Seul le code carré DataMatrix contient la date. Pour les autres boîtes, recopiez la date imprimée (souvent « EXP » ou « Pér. »). Si seul le mois est indiqué, mettez le dernier jour du mois.

L'indicateur affiche « erreur sync »

Le plus souvent, le jeton a expiré ou a été révoqué. Créez-en un nouveau (section 2, cas 2, étape 3) et collez-le dans Réglages. Vérifiez aussi le nom du dépôt (propriétaire/nom). Rien n'est perdu : les changements restent sur l'appareil et partiront à la prochaine synchronisation.

Une boîte ajoutée sur le téléphone n'apparaît pas sur le PC

La synchronisation part quelques secondes après chaque changement. Sur l'autre appareil, les nouveautés arrivent quand on revient sur l'app. Vérifiez que les deux appareils utilisent le même dépôt, et touchez Synchroniser maintenant dans Réglages.

Comment obtenir la nouvelle version de l'app ?

Rien à faire : elle se met à jour toute seule à l'ouverture suivante. Si l'ancienne version reste affichée, fermez complètement l'app puis rouvrez-la.
